Overwrite Current Schedule?

Loading a new .yophline file will replace all current events and periods. Unsaved changes will be lost.

iCal (.ics) Format Notice

The Yoph Suite works best with native .yophline files, which preserve custom item styling, exact period durations, and timeline positions across Yoph apps.

Standard iCal (.ics) files will import basic events and periods, but non-standard Yoph color tags may be converted.
